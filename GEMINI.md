## 1. Source of Truth & File Ownership

### Authorized Editable Source Files
Treat the exported text files in this repo as authoritative:
- `Modules\**\*.bas`, `*.cls`, and `*.frm`/`*.frx`: Editable VBA source code.
- `features.json`: Definitive manifest for Ribbon controls, commands, icons, and hotkeys.
- `config.json`: Configuration for UI and safety threshold constants.

### Files Never to Edit Manually
- `Beaver Add-in.xlsm`: Autogenerated workbook artifact. Always use `Update.ps1` to compile changes.
- `ribbon.xml`, `Modules\Infrastructure\Infra_CommandRegistry.bas`, `Modules\Libraries\Lib_TestManifest.bas`: Autogenerated by the build system.
- `Modules\Libraries\Lib_JsonConverter.bas`: Third-party library.

## 2. Development & Verification Workflow

Always use the unified build pipeline (`Update.ps1`) to compile code, inject the Ribbon UI, run linters, and verify tests.

### Fast-Iteration Workflow (COM Session Keep-Alive)
Use these PowerShell commands from the repository root:
```powershell
# incremental build + run tests with Excel session kept open (Under 1.5s iterations)
.\Update.ps1 -KeepAlive

# targeted testing for specific features
.\Update.ps1 -Filter "CleanData" -KeepAlive

# run full test suite and close Excel (Execute this before concluding any task)
.\Update.ps1
```

### AI Agent Pipeline Parameters
* **`-FailedOnly`**: Retries only previously failed unit tests parsed from the build log. If no tests failed last run, it immediately skips execution, avoiding Excel startup overhead.
* **`-Format Json`**: Bypasses human-formatted text output and outputs the final pipeline status/errors as a single parseable JSON object on standard output.
* **`-AutoFix`**: Automatically repairs linter style violations (e.g. missing `Option Explicit` or `@Module` headers) directly on disk, inserting them correctly after any VBE attribute lines.
* **`-ShowDeps <Module>`**: Prints the dependency tree of a module along with its recursive dependents to perform a pre-refactoring impact assessment (use `"all"` for the entire project).

### Verification Checklist before Concluding a Task
1. Run the full `.\Update.ps1` (with no filters or flags) to ensure clean VBE compilation and Custom UI load.
2. Confirm that all 500+ unit tests pass successfully.
3. Ensure no manual changes were made to generated files.

## 3. Core Architecture & Design Patterns

The add-in is command-oriented:
`Ribbon / Hotkey Trigger` $\rightarrow$ `UI Callback (UI_Ribbon / UI_Hotkeys)` $\rightarrow$ `AppContainer.ExecuteEntryPoint` $\rightarrow$ `CommandInvoker.ExecuteCommand` $\rightarrow$ `FeatCmd_*.CanExecute & Execute`.

### Shared Infrastructure Rules
* **Infra_AppStateGuard**: Captures and restores Excel application state (`ScreenUpdating`, `DisplayAlerts`, etc.). Always declare inline as `Dim guard As New Infra_AppStateGuard` for automatic cleanup.
* **Infra_Error**: Centralizes error tracking. Public entry points must use `On Error GoTo` wrapping a tracked context via `Infra_Error.Track`.
* **Infra_Undo**: Buffers range state for custom undo logic inside a private sheet. Check selection thresholds using `Infra_Undo.SaveStateOrConfirm` before range mutations.

## 4. UI/UX Design System Rules

When building or modifying user interfaces, you must adhere strictly to these patterns:
* **Option Picker Flows**: Multi-choice or single-select picker lists must use `UI_OptionPicker` UserForm:
  - Layout is dynamically calculated via `ResizeOptionPickerLayout` based on string lengths.
  - Multi-select displays Unicode checkbox characters (`☐`/`☑`). Font must programmatically force **Segoe UI** to prevent checkbox misalignment.
  - Save and load picker states under distinct pref namespaces using the `prefNamespace` parameter.
* **Excel Icon Safety**: Use only natively supported Excel `imageMso` icons (e.g. `TableProperties`, `Clear`, `WorkbookLinks`, `Export`, `Help`). Avoid Word-only or Access-only icons to prevent Ribbon XML load crashes.

## 5. VBA Coding Guidelines

* **Option Explicit**: Mandatory at the top of every file.
* **Metadata Headers**: Declare categories and dependencies at the top of files using standard headers.
* **Bulk Performance**: Avoid cell-by-cell loops. Read ranges into variant arrays, perform bulk data operations, and write back in single operations.
* **Spill Awareness**: Use `AreaHasSpill` to verify dynamic spills and `ConvertRangeToValues` for optimizing formula flattening.
* **VBE Error Prevention**: Safely intercept literal cell errors (`CVErr()`) before type casting, and check properties for `Null` (using `IsNull()`) on multi-cell ranges to avoid runtime Error 94/13 crashes.
